# 餵小怪獸 原型企劃

2026-10-10

練習作品，不上架。目的是驗證兩件事，遊戲本身只做到能驗證為止。

## 驗證目標

1. **答題模組能乾淨地用在新遊戲。** 不沿用 MathQuestionGame 的程式碼，只參考它的題目格式與 eMath API，重新設計一個不依賴任何管理器、放進空專案就能用的模組。設計見 [QuestionModule.md](QuestionModule.md)。
2. **靠 AI coding 能多快做出一個小遊戲。** 由開發者自己用 AI 工具完成，並記錄過程（見文末「開發紀錄」），作為之後新人交接的參考。

## 怎麼算成功

- [ ] 答題模組可以複製到另一個空的 Unity 專案直接使用，不需要修改。
- [ ] 遊戲程式碼只透過模組的公開入口取題、判斷對錯，沒有直接碰網路或題庫檔案。
- [ ] 關掉網路，能完整玩一局（使用本機題庫）。
- [ ] 找一兩個小學生試玩，不用解釋就會操作。
- [ ] 記錄下開發總時數與卡住的地方。

## 遊戲概要

一隻肚子餓的小怪獸。題目的每個選項變成一個食物，把正確的食物拖給怪獸吃。吃得越多，怪獸會長大。

- 平台：平板（橫向）
- 對象：小學生，在家自己玩
- 一局：5 題，約 2～3 分鐘

## 一局的流程

1. 開始畫面：選年級（一上～六下），按開始。
2. 出題：畫面上方顯示題目圖片，下方依選項數量出現 3～4 個食物，每個食物標示選項編號。
3. 拖曳食物到怪獸嘴巴：
    - 答對：怪獸吃掉食物，飽足度 +1，進入下一題。
    - 答錯：怪獸把食物吐出來，同一題再選一次。
4. 5 題結束：結果畫面顯示「第一次就答對」的題數，以及這局增加的飽足度。
5. 飽足度累積達到門檻時，怪獸長大一個階段。

規則：

- 重選後答對仍可餵食，但只有第一次就答對的題目算「答對」。
- 答錯沒有其他懲罰，不扣分、不扣血。

## 怪獸成長

| 階段 | 累積飽足度 | 外觀 |
| --- | --- | --- |
| 寶寶 | 0 | 小、圓 |
| 小孩 | 15 | 中 |
| 大人 | 40 | 大 |

門檻數字是暫定值，試玩後再調。成長進度存在本機（`PlayerPrefs` 或 JSON 檔）。

## 範圍

**要做**

- 開始畫面（選年級）、遊戲畫面、結果畫面
- 拖曳食物餵食、答對與答錯的基本反應
- 怪獸三個成長階段（換圖片即可）
- 本機存檔：累積飽足度、目前階段、上次選的年級
- 線上題庫與離線題庫

**不做**

- 進化分支、圖鑑、取名、換顏色
- 每日題數上限、家長頁面、學習報表、帳號
- 音效、精緻動畫、多語言

## 畫面草圖

```
┌──────────────────────────────────────────┐
│  第 2 / 5 題                  飽足度 ███░ │
│  ┌────────────────────────────────────┐  │
│  │           題目圖片                 │  │
│  └────────────────────────────────────┘  │
│                                          │
│                (  怪獸  )                │
│                 張開嘴巴                 │
│                                          │
│   [🍎 1]    [🍌 2]    [🍇 3]    [🍓 4]   │
└──────────────────────────────────────────┘
```

eMath 的選項是一張圖（`OptionSprite`），不是每個選項各一張。所以食物上只標示編號 1～4，選項圖片放在題目圖片旁邊或下方。

## 美術

先用免費素材或簡單幾何圖形，能辨識就好：

- 怪獸：3 張（各階段一張），加上張嘴、開心、吐出三種表情就更好
- 食物：4 種
- 背景：1 張
